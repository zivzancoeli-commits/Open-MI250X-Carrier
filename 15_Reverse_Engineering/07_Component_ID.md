# Component Identification

# Purpose

Create a component inventory for the AMD Instinct MI250X OAM carrier-board project from local PDFs, photographs, and readable repository evidence. This file records manufacturer, part number, function, package, confidence level, datasheet status, and source document for every identified component or unresolved component category.

This file is not a purchasable BOM, schematic source, approved vendor list, footprint list, or visual teardown report. No component identity, package, part number, or datasheet is inferred from absent photos, invalid PDFs, indexed-only references, or general hardware knowledge.
