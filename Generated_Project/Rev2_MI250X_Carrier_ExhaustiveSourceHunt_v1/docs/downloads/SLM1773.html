PCIe x16 Gen4 with ReDriver to SlimSAS 8i Dual Port AIC

Part #SLM-1773-8I
$204.75

PCIe Gen 4 16GT/s SlimSAS 8-Lane (SFF-8654 8i) to PCI Express 4.0 convert AIC. Built-in ReDriver, 16 lanes differential pair signals, 4-Channel SMBus Switch & 100MHz Clock buffer. Compliant with SFF-8654 Specification Version 1.2 and supports Windows 7-10 & UEFI 2.3.1 or later.

More Information

Part # SLM-1773-8I
Bar Code (UPC) 611851924638
Specifications

‌PCIe x16 Gen4 with ReDriver to SlimSAS 8i Dual Port AIC

Features :

  •  SlimSAS 8i (SFF-8654) to PCIe x16 Gen4 convert 
  •  Built-in SFF-8654 8i connector x2pcs, pin define by SFF-9402 Rev1.1
  •  Built-in ReDriver to extend PCIe 4.0, 16GT/s 16 lanes differential pair signals data link width.
  •  The PCIe 16 lanes can be bifurcated into four x4 link width to support different system topologies
  •  Built-in PCIe 100MHz Clock buffer(Address: 0x6C) for SlimSAS 8i(SFF-8654) to drive longer cable length. 
  • It may be buffered and fanned out to the SlimSAS 8i(SFF-8654) clock pin.
  •  Built-in SMBus Switch(Address: 0x70) with Reset Funtion for SlimSAS 8i(SFF-8654) SMBus communication
  •  Built-in SMBus I/O Expander(Address: 0x20) for OOB(out of band) management to remote SlimSAS 8i
  • (SFF-8654) Reset signals.
  •  Supports PCIe PERST# management to control SlimSAS 8i(SFF-8654) Reset signals.
  •  Built-in PERST# Bus Buffer to be used over longer cable length.
  •  Built-in WAKE# Auto-Bidirectional Bus Buffer to be used over longer cable length.
  •  Built-in CLKREQ# Auto-Bidirectional Bus Buffer to be used over longer cable length.
  •  Built-in PWRBRK# Bus Buffer to be used over longer cable length.
  •  Built-in 12V to 3.3V, 5.5A PWM Power controller
  •  Built-in 3.3V Power Load Switch for ReDriver controller Power Protection. 
  •  The WAKE# signals power supply can choose +3.3V or 3.3VAUX, the default is 3.3VAUX
  •  LED1 Green LED on indicates AIC ready
  •  LED4 Green OFF indicates PERST# Normal (Function intentionally inverted) 
Specifications :
  • PCI Express Base Specification Rev 4.0 
  • PCIe_CEM_SPEC_R4_V1_0_08072019_NCB
  • Compliant with Support SFF-9402 Rev1.1
  • Compliant with SFF-8654 Specification Version 1.2
Operating Systems :
  • Windows 7
  • Windows 8 &8.1
  • Windows 10
  • UEFI 2.3.1 or later
