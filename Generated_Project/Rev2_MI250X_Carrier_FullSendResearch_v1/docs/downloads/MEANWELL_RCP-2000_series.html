2000-Watt Rack Mount Power Supply

RCP-2000

Description

The MEAN WELL RCP-2000 series are rack mountable front end power supplies. These power supplies are designed to be mounted into the RKP-1U cassette, which can hold up to 3 units. These 3 power supplies can be connected in parallel to deliver up to 6000-Watts of power. It should be noted that the RKP-1U cassette is ordered as a separate item.

The 1U low profile design means that little space is taken up in the rack by these power supplies. The RCP-2000 units are hot swappable, so there is no need to power down, should a unit need to be replaced.

These power supplies offer a high level of efficiency and feature active power factor correction.

The output voltage can be trimmed within a range of 90~110% by applying an external voltage. Remote on-off control and voltage drop compensation are also featured.

For remote status monitoring an isolated TTL signal is provided for both DC OK and AC OK. There is also an over temperature warning.

The RCP-2000 power supplies have I2C interface and support the PMBus protocol, which allows the power supply to be controlled and monitored via the RKP-CMU1 controller.
