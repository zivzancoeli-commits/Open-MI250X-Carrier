Supermicro MBD-X11DPH-T Server Motherboard

Supermicro MBD-X11DPH-T E-ATX server motherboard is ideal for high-performance, general-purpose server platforms. Featuring support for dual 2nd Generation Intel Xeon Scalable processors and whopping memory capacity, this server motherboard lets you build a powerful server system that crunch through massive datasets. It also offers ten SATA 3 (6Gbps) ports, seven PCI-E 3.0 x16/x8 slots, two PCI-E 3.0 x4 M.2 slots and dual RJ45 10GBase-T ports to let you expand freely to eliminate data processing bottlenecks for heavy server workloads.
