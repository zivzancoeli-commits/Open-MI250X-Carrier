# Buyable first system v1 — 2× MI250X OAM (NOT fab-ready)

**Copied tree.** Production KiCad under other `Rev2_*` folders was not modified. Schematic was not “Updated PCB from Schematic.”

**DO NOT FABRICATE. DO NOT ENERGIZE an MI250X on this board.**

This folder is the maximum evidence-based 2-OAM carrier stub that can be drawn from:

- OCP generic **v1.0** 688+688 pad map (`22_Pinmap_Research/`, merged from PR #1)
- OCP v1.5 mechanical envelopes already in `Rev2_MI250X_Carrier_ChassisEnvelope_v1`
- The locked first system (X11DPH-T, Gold 6230, Optane PMem 100, NH-U14S DX-3647, welded dual-chamber chassis)

It is **not** an AMD MI250X NDA overlay. TEST/RFU/DO_NOT_USE pads have **no nets**. SerDes S1–S7 are named and assigned on the PCB, **not routed** (xGMI topology unknown).

## Regenerate (do not hand-edit pad nets)

```bash
python3 Generated_Project/Rev2_MI250X_Carrier_BuyableFirstSystem_v1/tools/generate_from_v10_pinmap.py
```

If the CSV and the xlsx disagree, **the xlsx wins** (`22_Pinmap_Research/downloads/OAM_Pin_map_rev_1.0.xlsx`).

## Fabricate / energize gates (all still open)

1. 48 V source **and** harness to P48V (Dell D3000E-S1 is **12 V**, not GPU power)
2. Molex 218910-1115 voltage rating vs P48V (Farnell sheet **30 V max** vs OCP **44–59.5 V**)
3. Connector PIN A3 orientation checked on a plot
4. Real cooling (not a custom cold plate on bare die)
5. AMD overlay unknowns listed in `docs/Blockers.md`

KiCad was **not** available in this cloud environment (`kicad-cli` missing). Artifacts are schematic/net/BOM/PCB sexpr generated by the script.
