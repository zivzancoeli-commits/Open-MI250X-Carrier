# 02_AMD_Docs

## Purpose
This folder exists to capture upstream public repositories before they are mirrored, extracted, or used as evidence. It is the entry point for web-based OAM, AMD, ROCm, and MI250X references.

## Engineering Questions
- Where is the official OAM specification source?
- Which public sources mention OAM mechanical drawings, connector specification, and power specification?
- What public examples or benchmarks exist for AMD matrix cores?
- Are there public ROCm or MI250X software-support references worth tracking?

## Known Information
- `GitHub_Links.rtf` lists the OAM specification, AMD matrix core benchmarks, and a Tiberius AMD fork.
- The OAM link is described as useful for mechanical drawings, connector specification, and power specification.
- The matrix-core link is described as useful for examples and performance measurements.
- The Tiberius AMD fork is described as useful for ROCm compatibility and MI250X software support.
