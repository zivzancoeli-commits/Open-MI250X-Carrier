\f0\fs24 \cf0 # System Goals\
\
## Primary Goal\
\
Design an open carrier board capable of operating surplus AMD Instinct MI250X OAM accelerators.\
\
---\
\
## Long-Term Goals\
\
- Support 1 MI250X\
- Support 2 MI250X\
- Support 4 MI250X\
- Support 8 MI250X\
\
---\
\
## System Requirements\
\
The final system should:\
\
- Minimize overall cost\
- Use publicly available documentation\
- Use open standards where possible\
- Avoid proprietary server hardware when practical\
- Support future PCB revisions\
- Be maintainable by the community\
\
---\
\
## Hardware Goals\
\
- OAM compliant\
- PCIe Gen4\
- Reliable power sequencing\
- Reliable clock generation\
- Simple management controller\
- Replaceable cooling solution\
\
---\
\
## Project Priorities\
\
1. First successful boot\
2. Stable PCIe enumeration\
3. Reliable operation\
4. Multi-GPU support\
5. Cost optimization}
